个人简介

我是广东工业大学博士生导师、二级教授，现任数据挖掘与信息检索实验室主任，国家优秀青年科学基金获得者。现兼任广东省媒体融合与数字创意重点实验室副主任、学术带头人。 我分别于2005年和2010年获得华南理工大学应用数学学士学位和计算机科学博士学位。 我的研究主要围绕因果发现、因果学习与深度学习的理论及应用展开。我主持了国家优秀青年科学基金、科技部 “科技创新 2030” 重大项目、国家自然科学基金 - 区域创新发展联合基金（广东）等多项重点课题。 我曾获得广东省自然科学奖、中国专利奖等奖项。 现担任 IEEE TPAMI 副主编、Neural Networks 执行编委、Fundamental Research 青年编委，并担任 NeurIPS、ICML、ICLR 等会议的领域主席（Area Chair）。

我的研究围绕人工智能底层一个尚未解决的问题：大多数 AI 模型能揭示变量间的相关性，却无法回答 “改变 X 后 Y 会如何变化，以及背后的原因”—— 这正是因果问题，也是网络故障诊断、临床决策、营销定价等真实场景中一切可靠决策的核心。 在开放、嘈杂的真实世界中实现稳定的因果建模，是当前领域的前沿挑战。DMIR 实验室是国内最早专注于因果发现与因果机器学习的团队之一，我们致力于补上大模型的关键短板：不只是认识“世界是什么”，而是理解“如果我们行动，世界会变成什么样”。

CDFM — 因果发现基础模型

CDFM 是面向零样本因果发现的预训练基础模型。模型以观测数据为输入，通过一次前向推理预测因果图。其预训练过程利用多样化的合成结构因果模型，使模型学习有助于因果结构推断的统计不对称性。

01零样本因果图推断

同一个预训练模型面向不同样本规模和变量数量的数据集，无需针对每个任务重新微调。

02多机制族评测

项目 README 报告了跨 15 类机制族及真实数据基准的实验比较。

03缺失值填补

除因果图发现外，模型还提供内置的缺失值填补模块。

TSC-FM Benchmark — 时间序列分类基础模型评测基准

TSC-FM 是面向时间序列分类基础模型的公开评测基准。官方网站整合了排行榜、数据集概况、方法介绍、能力分析，以及支持透明、可复现比较的评测协议。

TSC-FMBENCHMARK FRAMEWORK
时间序列分类基础模型评测框架
Standard官方训练/测试划分
Low-shot匹配的少样本标签预算
Training-Free / ICLFrozen-Probe
排行榜 · 数据集概况 · 能力图谱 · 评测协议
01可比较的排行榜

提供 Overall、Standard 和 Low-shot 等结果视图，并在适用范围内展示数据模态和数据集覆盖情况。

02透明的评测协议

协议区分标签预算与预测方式：Standard、Low-shot 描述标签预算；Training-Free / ICL、Frozen-Probe 描述评测方法。

03模型能力分析

按照数据模态和数据集属性分析汇总结果，并明确展示统计范围与覆盖情况。

官方评测平台 ↗排行榜 ↗数据集概况 ↗能力图谱 ↗评测协议 ↗

数据集数量、排行榜分数和覆盖范围以官方平台实时公布的信息为准，避免在个人主页中固化可能变化的统计数字。

causal-learn — Python 因果发现工具库

causal-learn 是面向研究人员和实践者的开源 Python 因果发现工具库。它集成了多类因果发现算法，同时提供模块化组件，便于开发和评估新的因果发现方法。

01多类因果发现范式

包括约束类、评分类、函数因果模型、隐变量因果表征、基于排列的方法和 Granger 因果方法。

02可复用的研究组件

提供独立性检验、评分函数、图操作和评估工具，支持进一步的方法开发。

03研究与学习资源

提供 Python API、示例、项目文档，并有经过同行评审的 JMLR 软件论文。
